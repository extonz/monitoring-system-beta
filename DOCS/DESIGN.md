# DESIGN.md

## Visual Direction

Create a premium desktop application with a design language inspired by Apple's
macOS System Settings, Finder and modern Apple utilities.

The application must feel:
- Calm
- Premium
- Minimal
- Precise
- Native
- Trustworthy
- Extremely polished

This is NOT a generic SaaS dashboard.

## Avoid

Do NOT use:
- Purple AI gradients
- Huge rounded cards everywhere
- Excessive glassmorphism
- Generic Tailwind dashboard layouts
- Random colorful icons
- Giant headings
- Excessive borders
- Fake security percentages
- Hacker/cyberpunk aesthetics
- Neon green/red cybersecurity visuals
- Unnecessary animations
- Generic "AI app" visual patterns

## Layout

Prefer:
- Strong visual hierarchy
- Generous spacing
- Restrained use of containers
- Clear typography
- Small and meaningful controls
- Subtle separators
- Consistent alignment
- Content that breathes
- Dense information only when useful

The interface should feel like a real operating-system utility,
not a website placed inside a desktop window.

## Color

Use a restrained neutral palette.

Security states should be communicated primarily through:
- typography
- subtle accents
- small indicators
- iconography

Do not turn the entire interface red whenever something suspicious happens.

Critical events should feel important without becoming frightening.

## Typography

Typography must be highly intentional.

Use a clean system-like sans-serif.

Prioritize:
- hierarchy
- readable sizes
- proper line height
- restrained font weights

Avoid oversized marketing typography.

## Components

Components should be simple and purposeful.

Prefer:
- native-feeling controls
- compact buttons
- segmented controls where appropriate
- subtle sheets/dialogs
- unobtrusive status indicators
- contextual information

Do not turn every section into a card.

## Motion

Animations should be:
- subtle
- short
- purposeful
- smooth

Use motion to communicate state changes, not to decorate the interface.

## Core principle

Every visual element must have a reason to exist.

When choosing between a more visually impressive design and a
more restrained design, prefer the restrained design.

The final result should look like a product designed by a
professional product-design team, not an AI-generated template.
